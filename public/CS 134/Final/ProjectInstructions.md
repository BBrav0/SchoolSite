The final project is to plan, design, build, and publish a small-scale web site.

you will be developing a Web site consisting of 7 to 10 web pages written in HTML elements.  

The final project will include all HTML elements from labs in the previous folders in cs 134 directory.  They will include, but are not limited to internal and external hyperlinks, images, tables, forms, JavaScript, and CSS.  The structure and the content of the web site are up to you

NOTE:

* The navigation system should function to show the user where they are and where they can go.  You should plan and show navigation to other parts of the site, even if the links are not active.  
* One of these pages should contain a "function" component that uses JavaScript.  
* The pages you produce should be "ready for launch". Your pages should be done well and should work properly.  
  Some examples of things you might consider:  
  * Well-organized file structure  
  * Re-use of CSS, JS, and images  
  * Include at least one table that shows tabular data  
  * Include at least one form  
  * Consistency throughout pages in header, footer, navigation, and potentially other elements  
  * Well-chosen titles that stand on their own  
  * "meta" keywords and description appropriate for each page  
  * Print CSS rules  
  * Custom error documents

Some basic guidelines as you continue working on your project:

* Use a [directory system (Links to an external site.)](http://www.seattlecentral.org/faculty/ymoh/mic151campus/week3/directory/directory.htm).  The site needs to be organized in directories/folders according to the nature of relatedness to each other.  
* The file name of the default or the home page should be either **index.htm** or **index.html**.  Be sure to build your site in a new folder (directory), and the index page should be inside the folder.

Check out these sites for inspirations:

* Top HTML Projects with Source Code: [https://www.interviewbit.com/blog/html-projects/](https://www.interviewbit.com/blog/html-projects/)
